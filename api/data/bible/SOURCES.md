# Bible text

Both translations are in the public domain. They are stored here so scripture
is looked up exactly, with no outside service and no guessing.

| File | Translation | Source |
|---|---|---|
| `kjv.tsv.gz` | King James Version | eBible.org, `eng-kjv2006_vpl.zip` |
| `web.tsv.gz` | World English Bible, American edition with "the LORD" | eBible.org, `engwebp_vpl.zip` |

Each line is `book` (1 to 66, Genesis to Revelation), `chapter`, `verse`, and
the text, separated by tabs.

Changes from the source: paragraph marks (¶) are removed, and the brackets
the KJV source uses for words the translators added (printed in italics in a
Bible) are removed, keeping the words.

"World English Bible" is a trademark of eBible.org.
